yt-shorts-studio

One long interview → ready-to-post 9:16 Shorts + Reels. Paste a link, copy the command, run it locally.

python3 pipeline.py --url …
Then, locally:

1. One-time setup: pip install yt-dlp faster-whisper and brew install ffmpeg (macOS) / apt install ffmpeg (Linux).

2. Paste the command in the repo folder. It downloads, transcribes with word timestamps, scores highlights, cuts 9:16 clips with burned captions.

3. Output lands in output/<video-id>/ — the short*.mp4 files plus POSTING_CHECKLIST.md with hooks, captions, and hashtags ready to paste.

4. Upload manually to YouTube Shorts + Instagram Reels (no personal-account APIs exist). ~5 minutes.

Bot-walled? Drop a word-timestamp JSON and use --transcript words.json to skip download + whisper.
